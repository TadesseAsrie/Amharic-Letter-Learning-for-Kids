# 🇪🇹 Amharic Letter Learning for Kids

An interactive educational web application designed to help children learn the **Amharic (Geez) alphabet (ፊደል)** through engaging lessons, games, quizzes, writing practice, pronunciation, and reward-based activities.

The application is built using **HTML5**, **CSS3**, and **Vanilla JavaScript**, making it lightweight, responsive, and easy to run in any modern web browser without requiring any external frameworks.

---

## 📚 Features

### 🎓 Learning Module
- Learn all Amharic (Geez) letters
- Letter pronunciation
- Example words with illustrations
- Letter stroke order
- Audio playback
- Interactive flashcards

### ✍️ Writing Practice
- Canvas-based handwriting practice
- Letter tracing
- Stroke guide
- Undo/Redo
- Clear canvas
- Writing accuracy checking
